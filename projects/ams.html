AMS Helpdesk Portal

June - August 2018

The AMS (Abiliti Management System) Helpdesk Portal was created to allow Morneau Shepell clients to access data stored in the back-end using a clean user interface. My design was based off of the 6 functions needed for the portal: Employee Search, Claim Lookup, Audit Trail, Remove Claim, Upload File, and Demographic History. CSS Flexbox and Grid were heavily used in my code as there were many grid components in the design.

UI Design Decisions

  • Desk illustration helps further engrain the "helpdesk" function of the site (and is modelled after my own desk at the office)
  • Each function has a Morneau Shepell brand-colored icon to illustrate its task
  • A pin-protected "Private Info" tab to access an employee's sensitive information, such as SIN
  • Tables to display previously cluttered information in lists
